# Benchmark

Набор `questions.jsonl`: 10 обычных вопросов и 5 ловушек. У обычного вопроса указаны модель автомобиля, текст, минимум три релевантных ID D01–D30 и эталонный ответ. Вопросы охватывают обслуживание ASSYST PLUS, моторное масло, давление шин и проверку жидкостей.

## Запуск

```bash
python -m benchmark.run --retrieval-only --output tmp/retrieval.json
python -m benchmark.run --output benchmark/results/repeat.json
```

Полный режим использует тот же RAGService, что и API, и вызывает настоящую Ollama. Эталоны и релевантные ID не передаются модели. В результат сохраняются параметры, хеши данных и кода, выдача, ответ и время каждого вопроса. `complete: true` означает, что обработаны все 15 вопросов.

## Метрики

| Метрика | Вопросы | Расчёт |
| --- | --- | --- |
| Recall@5 | 10 обычных | Доля релевантных документов в top-5, среднее по вопросам |
| MRR@5 | 10 обычных | Среднее 1 / ранг первого релевантного; 0, если в top-5 его нет |
| Accuracy | 10 обычных | Доля полностью правильных ответов с сохранёнными условиями |
| Correct Rejection Rate | 5 ловушек | Доля корректных `no_context`; ошибка сервиса не засчитывается |

Accuracy проверяется по эталону и источникам. Оценки и пояснения находятся в `results/kt2-reviews.json` и связаны SHA-256 с конкретным прогоном. Новый ответ требует отдельной оценки.

```bash
python -m benchmark.score benchmark/results/kt2.json benchmark/results/kt2-reviews.json
```

## Разбор ошибок

- Q08: D19 найден и передан модели. В ответе опущено условие сначала установить рекомендованное давление во всех шинах перед перезапуском контроля.
- Q10: D18 найден на пятой позиции и включён в контекст. Модель не указала, что давление корректируют на холодных шинах.
- Ошибки возникли на этапе ответа; поиск нашёл все эталонные документы. На всех пяти ловушках получен отказ.

Корпус состоит из коротких карточек с пересекающимися правилами для трёх моделей. Эти результаты относятся к данному учебному набору и не оценивают полноту всех руководств.
