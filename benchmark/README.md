# Benchmark

Размеченный набор запросов и результаты ещё не созданы. `questions.example.jsonl` — только пример формата (`split: "example"`), в метриках не участвует. Отвечает участник с ролью LLM, запросы предлагают все.

## Формат запроса

| Поле | Описание |
| --- | --- |
| `id` | Идентификатор запроса |
| `split` | `dev` — для настройки, `holdout` — для итоговой оценки, `example` — пример формата |
| `model_code` | Выбранный автомобиль: `W205`, `W213`, `X253` |
| `topic` | Тема из сетки покрытия в [testing.md](../spec/tech/testing.md#тестовый-набор-запросов) |
| `query` | Запрос пользователя, сформулированный не копированием текста документа |
| `expected` | `answer`, `clarify` или `no_context` |
| `relevant` | Релевантные фрагменты: `doc_id` и `page`; для `answer` — **не менее трёх** |
| `reference_answer` | Эталонный ответ, проверенный человеком |
| `author`, `reviewer` | Кто составил и кто проверил разметку |

Метрики и эксперименты — [spec/tech/testing.md](../spec/tech/testing.md).
