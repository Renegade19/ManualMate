# История изменений

Краткий журнал значимых изменений. Полная история — в коммитах и Pull Request.

## 2026-10-23 — новый дизайн интерфейса

- Интерфейс переделан в стиле справочника Mercedes-Benz: чёрный первый экран с вкладками C-Класс, E-Класс, GLC; строка вопроса; шесть быстрых тем с частыми вопросами; ответ оформлен как страница документа со сносками и раскрываемыми фрагментами.
- Из интерфейса убраны «чат-ботовые» элементы: блок «как это работает», этапы «языковая модель», пилюли и бейджи.
- Обновлены [interface.md](spec/product/interface.md), [scenarios.md](spec/product/scenarios.md), скриншоты, решение D13.

## 2026-10-23 — оформление к контрольной точке 1

- Выбрана предметная область: Mercedes-Benz C-класс (W205), E-класс (W213), GLC (X253). Причины — в [журнале решений](spec/decisions.md).
- Добавлены спецификации: `spec/product/`, `spec/tech/`, команда, план, журнал решений.
- Прототип интерфейса перенесён в `frontend/` как статические HTML, CSS и JS и переведён с BMW на Mercedes-Benz: выбор модели и двигателя, состояния «ответ», «уточнение», «нет данных», «ошибка сервера».
- Добавлены `AGENTS.md`, `CONTRIBUTING.md`, шаблон PR, `scripts/check_docs.py` и проверка в GitHub Actions.
- Добавлены `docs/`: чек-лист точки, сценарий показа, источники, отчёт проверки, скриншоты.
- Добавлены README-границы будущих компонентов: `backend/`, `search/`, `corpus/`, `benchmark/`.

## 2026-10-09 — первый прототип

- Интерактивный прототип интерфейса (на тот момент — для BMW 3 Series G20).

## 2026-10-07 — старт проекта
