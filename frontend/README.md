# Frontend

HTML, CSS и JavaScript без сборки. Рабочий интерфейс раздаётся FastAPI по адресу <http://127.0.0.1:8000>.

| Файл | Назначение |
| --- | --- |
| `index.html`, `styles.css` | Разметка и оформление |
| `script.js` | Состояния экрана, выбор автомобиля, вопросы, источники |
| `api.js` | HTTP-запросы, проверка JSON, отмена, тайм-аут |
| `config.js` | Адрес API и тайм-аут |
| `demo.js` | Прототип КТ1, доступен при `?demo=1` |

Автомобили загружаются из `/api/vehicles`, вопрос отправляется в `/api/ask`. Источники раскрываются по сноске. Подсвечиваются исходные `matched_terms` сервера. При смене автомобиля запрос отменяется. Ответы и фрагменты выводятся через `textContent`.

При отдельном сервере `python3 -m http.server 8080 --directory frontend` адрес backend задаётся в `config.js`. По умолчанию используется один origin. Список разрешённых отдельных origin задаётся backend через `FRONTEND_ORIGINS`.
