# API

Контракт между frontend и backend. Реализации пока нет; frontend уже возвращает демо-ответ той же формы из `askAssistant()` в `frontend/script.js`.

## `GET /api/vehicles`

Модели и двигатели, по которым есть документы.

```json
{
  "vehicles": [
    {
      "model_code": "W213",
      "name": "E-класс",
      "body": "Седан",
      "years": "2016–2022",
      "engines": [
        { "code": "M264", "label": "M264 — бензин 2.0" },
        { "code": "OM654", "label": "OM654 — дизель 2.0" }
      ],
      "documents": 4
    }
  ]
}
```

## `POST /api/ask`

**Запрос**

```json
{
  "question": "Что входит в сервис B?",
  "vehicle": { "model_code": "W213", "engine": "M264" }
}
```

| Поле | Тип | Обязательно | Описание |
| --- | --- | --- | --- |
| `question` | string | да | 1–500 символов |
| `vehicle.model_code` | string | да | `W205`, `W213` или `X253` |
| `vehicle.engine` | string | нет | Код двигателя; уточняет поиск, но не исключает общие фрагменты |

**Ответ 200** — одно из трёх состояний, поле `status`.

`answer` — ответ по найденным фрагментам:

```json
{
  "status": "answer",
  "intro": "Сервис B — расширенный объём работ по сравнению с сервисом A ...",
  "points": [
    { "text": "Замена моторного масла и фильтра ...", "citations": [1, 2] }
  ],
  "warning": null,
  "sources": [
    {
      "n": 1,
      "chunk_id": "w213-manual-p412-c2",
      "doc_id": "w213-manual",
      "title": "Руководство по эксплуатации E-класса (W213)",
      "section": "Техническое обслуживание · ASSYST PLUS",
      "page": 412,
      "score": 8.41,
      "text": "Полный текст фрагмента ...",
      "matched_terms": ["сервис", "b"]
    }
  ]
}
```

`clarify` — запрос неоднозначен:

```json
{
  "status": "clarify",
  "message": "Какое масло вас интересует? Ответ зависит от узла автомобиля.",
  "options": [
    { "label": "Моторное масло", "question": "Какое моторное масло подходит для моего двигателя?" },
    { "label": "Масло в АКПП", "question": "Какое масло заливается в АКПП?" },
    { "label": "Тормозная жидкость", "question": "Какая тормозная жидкость нужна?" }
  ]
}
```

Нажатие на вариант отправляет его `question` как новый запрос.

`no_context` — в документах ответа нет:

```json
{
  "status": "no_context",
  "message": "В документах базы знаний нет ответа на этот вопрос.",
  "searched": [ { "doc_id": "w213-manual", "title": "Руководство по эксплуатации E-класса (W213)", "hits": 0 } ]
}
```

| Поле | Описание |
| --- | --- |
| `points[].citations` | Номера `n` из `sources`, на которые опирается пункт |
| `sources[].page` | Страница печатного руководства, а не номер страницы PDF-файла |
| `sources[].score` | Оценка BM25; показывается в панели фрагментов, но не как «процент уверенности» |
| `sources[].matched_terms` | Термы запроса после предобработки, найденные во фрагменте; frontend подсвечивает их |

**Ошибки**

| Код | Когда | Тело |
| --- | --- | --- |
| 400 | Пустой или слишком длинный вопрос | `{ "error": "question_invalid" }` |
| 404 | Неизвестная модель | `{ "error": "vehicle_unknown" }` |
| 503 | Недоступны LLM или индекс | `{ "error": "service_unavailable" }` |
| 500 | Внутренняя ошибка | `{ "error": "internal" }` |

При любой ошибке frontend показывает состояние «Ошибка» с кнопкой «Повторить».

## `GET /api/health`

```json
{ "status": "ok", "index_loaded": true, "chunks": 1840, "llm": "available" }
```

## Расширения следующих этапов

- `GET /api/chunks/{chunk_id}` — фрагмент с соседним контекстом.
- `debug=true` в `/api/ask` — термы запроса и top-20 с оценками для разбора ошибок benchmark.
