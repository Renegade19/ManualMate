# Проверка КТ2

```bash
python3 scripts/check_docs.py
python -m pytest -q
python -m benchmark.run --output benchmark/results/repeat.json
```

Тесты в `tests/` проверяют ручной пример BM25 из лекции, частоты и длины документов, детерминированность, фильтр модели, пустую выдачу, токенизацию обозначений, загрузку индекса, API, проверку ссылок и чисел, формулы метрик.

Benchmark: 30 документов, 10 обычных вопросов с ≥3 релевантными ID и эталонами, 5 ловушек. Recall@5 и MRR@5 считаются только по обычным вопросам. Accuracy — полностью правильные ответы из 10, Correct Rejection Rate — корректные отказы из 5. Ошибка сервиса не считается отказом. Полный ответ, выдача и параметры каждого прогона сохраняются в `benchmark/results/`.

Интерфейс: вопрос → ожидание → ответ и источник; уточнение; отказ; ошибка и повтор; смена модели во время поиска; ширины 1440 и 390 px. Текст сервера отображается как текст, демо помечено отдельно.
