# Журнал решений

| D01 | Предметная область — Mercedes-Benz C-класс W205, E-класс W213, GLC X253 (2014–2022) | Общие двигатели M274, M264, OM654: одни и те же сведения встречаются в нескольких документах, что нужно для требования «≥3 релевантных документа на запрос». Много машин в России, понятный пользователь. До 2022 года выпускались официальные руководства на русском | Официальные русские PDF ещё нужно найти и проверить; если по какой-то модели их нет, модель заменяется (кандидаты — CLA C117, GLE W166) |
| D02 | Отказались от BMW | Сроки ТО у BMW задаёт CBS: в руководствах почти нет явных интервалов. Официальных русских руководств на G20/G30/G05 в открытом доступе не нашли | — |
| D03 | Регламент описываем через сервисы A и B (ASSYST PLUS) | У Mercedes-Benz есть фиксированные пакеты работ, что удобно для фрагментов и запросов | Сроки ASSYST рассчитывает динамически; конкретные интервалы берём только из документов |
| D04 | Собственная реализация BM25 | Требование методических указаний: готовые поисковые индексы запрещены | Нужно самим покрыть тестами и оптимизировать |
| D05 | Лемматизация `pymorphy3` + сохранение технических обозначений | Русский текст с большой морфологией; обозначения вроде «5W-30», «MB 229.5», «OM654» нельзя разбивать и лемматизировать | Ошибки разбора редких терминов; проверяется экспериментом E1 |
| D06 | Фильтр по выбранной модели до ранжирования | Руководства трёх моделей похожи; без фильтра ответ для C-класса может прийти из руководства GLC | Общие документы (жидкости, сервисы) помечаются всеми моделями |
| D07 | Python + FastAPI | Один язык для API, индекса и экспериментов | Производительность достаточна для учебной нагрузки |
| D08 | Локальная LLM через Ollama | Без платных ключей и передачи данных во внешние сервисы | Нужен компьютер с достаточной памятью; модель выбирается по benchmark |
| D09 | Статический frontend без сборки | Быстрый показ на точке 1, ноль зависимостей | Пересмотреть, если интерфейс сильно вырастет |
| D10 | Исходные PDF не храним в Git | Руководства защищены авторским правом и тяжёлые | В Git — `manifest.json` с источником и хешем, извлечённый текст хранится локально |
| D11 | Роли Backend, Frontend, LLM | Решение команды; BM25 у Backend, предобработка текста и качество — у LLM ([team.md](team.md)) | Контракт между модулями фиксируется заранее |
| D12 | `main` + короткие ветки задач + Pull Request | Три участника, частая интеграция, видимая история в Git | Нужен регулярный review |
| D13 | Интерфейс в стиле справочника Mercedes-Benz: чёрный первый экран, вкладки моделей, быстрые темы, ответ как страница документа со сносками | Пользователь работает с документацией, а не с «чат-ботом»; быстрые темы закрывают частые вопросы одним нажатием. Выбран из четырёх макетов командой | Логотип и фирменные шрифты Mercedes-Benz не используются (товарные знаки); в подвале указано, что сервис не официальный |
