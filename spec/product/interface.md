# Интерфейс

Одностраничное приложение без входа в систему. Интерфейс оформлен как справочник владельца, а не как чат: вопрос задаётся в строке поиска, ответ выглядит как страница документа со сносками на источники. Скриншоты — [docs/images](../../docs/images/).

## Структура экрана

| Область | Состав |
| --- | --- |
| Верхняя полоса (чёрная) | Название ManualMate, подпись «Справочник по техническому обслуживанию», метка «Демо-версия» |
| Первый экран (чёрный) | Крупное название модели, тип кузова и годы; вкладки моделей **C-Класс W205 · E-Класс W213 · GLC X253**; выбор двигателя |
| Поиск (светло-серая полоса) | Поле «Вопрос по обслуживанию», кнопка «Найти ответ», подсказка про Enter и счётчик символов |
| Быстрые темы | Шесть вкладок с иконками: Сервис A и B, Моторное масло, Тормоза, Шины и давление, Охлаждение, Сообщения на панели |
| Результат (слева) | Одно из состояний ниже |
| Боковая колонка (справа) | «Частые вопросы» по выбранной теме; «Документация в базе» для выбранной модели; пометка, что страницы и фрагменты — примеры |
| Подвал | «Учебный проект НИРС» и «Не является официальным сервисом Mercedes-Benz» |

## Быстрые темы

- Нажатие на тему выделяет её и показывает справа три-четыре частых вопроса. Нажатие на вопрос сразу отправляет его.
- Если вопрос введён вручную, тема определяется по ключевым словам («шины», «давление» → «Шины и давление») и выделяется автоматически.
- Над ответом указывается тема: «Шины и давление · ответ по документации».
- В рабочей версии список тем и частые вопросы берутся из сетки покрытия benchmark ([testing.md](../tech/testing.md#тестовый-набор-запросов)), чтобы каждая тема была покрыта документами.

## Состояния результата

| Состояние | Что видит пользователь |
| --- | --- |
| Пусто | «Задайте вопрос или выберите тему» и одна фраза о том, что ответы составляются только по документации |
| Поиск | Вопрос, тонкая полоса загрузки, «Подбираем разделы руководства и сервисных документов…» |
| Ответ | Тема, метка «Пример», вопрос, вводный абзац, нумерованные пункты со сносками ¹ ² ³, примечание, список источников (документ, раздел, страница). «Показать фрагмент» раскрывает текст фрагмента с выделенными словами запроса и оценкой BM25 |
| Уточнение | «Требуется уточнение», пояснение и кнопки вариантов; вариант отправляет готовый уточнённый вопрос |
| Не найдено | «Ответ не найден», список проверенных документов с числом совпадений, вопросы выбранной темы, которые есть в документации |
| Ошибка | «Ошибка соединения» и кнопка «Повторить» |

## Правила

- Сноска в ответе раскрывает соответствующий фрагмент и прокручивает к нему.
- В интерфейсе нет слов «ассистент», «нейросеть», «языковая модель»: пользователь работает со справочником. Техническая оценка BM25 показывается только внутри раскрытого фрагмента.
- Текст ответа и фрагментов выводится через `textContent`: HTML из ответа модели не исполняется.
- Выбранные модель и двигатель хранятся в `localStorage` и восстанавливаются после перезагрузки. Если хранилище недоступно, приложение работает без него.
- Пока идёт поиск, кнопка «Найти ответ» недоступна; новый вопрос заменяет предыдущий результат.

## Визуальный стиль

Сдержанный стиль в духе сайтов Mercedes-Benz: чёрный первый экран, белая страница, тонкие линии, прямые углы, один синий цвет `#0078d6` для ссылок. Заголовки — засечный шрифт Cormorant Garamond (Google Fonts, без сети подменяется на Georgia), основной текст — системный шрифт без засечек. Цвета заданы CSS-переменными в `:root` файла `frontend/styles.css`.

Логотип Mercedes-Benz и фирменные шрифты не используются: это товарные знаки, а проект не является официальным сервисом ([журнал решений](../decisions.md), D13).

## Адаптивность

| Ширина | Поведение |
| --- | --- |
| > 960 px | Две колонки: результат слева, частые вопросы и документы справа (300 px); темы — шесть равных ячеек |
| ≤ 960 px | Одна колонка, боковая колонка под результатом; темы листаются по горизонтали |
| ≤ 640 px | Название модели меньше, выбор двигателя на всю ширину, кнопка «Найти ответ» под полем, строки источников в два уровня |

## Подключение backend

Единственная точка подключения — функция `askAssistant(question, vehicle)` в `frontend/script.js`. Сейчас она возвращает демо-ответ той же формы, что описана в [api.md](../tech/api.md#post-apiask). Модели, двигатели и темы пока заданы константами `VEHICLES` и `TOPICS` в том же файле; модели позже загружаются с `GET /api/vehicles`.
