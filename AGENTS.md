# Правила репозитория для кодингового агента

Этот файл читает любой кодинговый агент (Claude Code, Codex, Cursor и др.) перед работой с репозиторием. Люди следуют тем же правилам — см. [CONTRIBUTING.md](CONTRIBUTING.md).

## Перед изменением кода

1. Прочитай [spec/product/](spec/product/) и [spec/tech/](spec/tech/), относящиеся к задаче.
2. Если меняется поведение, API или формат данных — сначала обнови нужную спецификацию.
3. Сделай изменение в короткой ветке задачи (`feat/…`, `fix/…`, `docs/…`).
4. Запусти проверки: `python3 scripts/check_docs.py`; после появления кода — тесты и benchmark.
5. Добавь запись в [CHANGE_HISTORY.md](CHANGE_HISTORY.md), если изменение заметно пользователю или команде.

## Ограничения проекта

- BM25 реализуется самостоятельно. Нельзя подключать готовые поисковые индексы: `rank-bm25`, `bm25s`, Elasticsearch, Whoosh, Lucene и аналоги. Лемматизатор (`pymorphy3`) использовать можно.
- Один и тот же токенизатор обрабатывает и корпус, и запрос.
- Ответ формируется только по найденным фрагментам. Если фрагментов нет — `no_context`, LLM не вызывается.
- Источники (`sources`) backend берёт из metadata фрагментов, а не из текста модели.
- Интервалы, объёмы и допуски не придумываются и не «подставляются для примера» в рабочем коде: только из документов корпуса.
- Демо-режим всегда виден в интерфейсе.
- Текст модели выводится в интерфейсе через `textContent`, а не как HTML.

## Где что лежит

| Путь | Что |
| --- | --- |
| `frontend/` | Статический интерфейс; точка подключения к API — `askAssistant()` в `script.js` |
| `backend/` | FastAPI-сервис (будет) |
| `search/` | Токенизатор, индекс, BM25 (будет) |
| `corpus/` | Исходные документы, извлечённый текст, `manifest.json` |
| `benchmark/` | Тестовые запросы и отчёты прогонов |
| `spec/` | Спецификации: источник правды о поведении системы |

## Что нельзя делать

- Коммитить секреты, токены, персональные данные, VIN реальных автомобилей.
- Выдумывать результаты тестов и метрики benchmark.
- Переписывать опубликованную историю `main` и делать force-push.
