# Корпус КТ2

В Git хранится 30 коротких документов D01–D30: по десять адаптированных карточек из руководств W205 (09/2018), W213 (06/2020) и X253 (03/2020). Документ для поиска — карточка, как определено в [rag.md](../spec/tech/rag.md). Это не 30 отдельных PDF и не полный регламент. Карточки пересказывают выбранные разделы своими словами, поле `adapted: true`; точные формулировки и дополнительные условия проверяются по указанной странице оригинала.

Темы: срок ТО в ASSYST PLUS, тяжёлые условия эксплуатации, отключённая батарея; электронная проверка масла, безопасный долив, присадки и перелив; таблица давления шин, холодные шины, перезапуск контроля; меры предосторожности с охлаждающей жидкостью. Числовые допуски, универсальные интервалы замены и полный состав сервисов A/B в эту выборку не входят.

## Файлы

| Путь | Содержимое |
| --- | --- |
| `manifest.json` | Три исходных руководства: ссылка, издание, SHA-256, модель, смещение печатной страницы |
| `selection.json` | 30 карточек, PDF-страницы и якоря исходного текста |
| `processed/documents.jsonl` | Готовые документы и metadata для индекса |
| `raw/` | Локальные исходные PDF; исключены из Git |

`doc_id` и `chunk_id` — D01–D30; `source_id` — ID физического руководства в manifest. `page` — печатная страница; `pdf_page` — номер страницы PDF, начиная с 1. У выбранных изданий `page = pdf_page - 3`; номера проверялись по колонтитулам. Двигатели не размечены: `engines: []`, фильтр применяется по модели.

## Воспроизведение

```bash
python scripts/prepare_corpus.py --download
```

Скрипт скачивает недостающие PDF по ссылкам из каталога МБ РУС, проверяет SHA-256 всего файла и наличие якоря на каждой выбранной странице, затем детерминированно собирает JSONL. Изменение PDF вызывает ошибку проверки: новую редакцию нужно проверить отдельно. Полный извлечённый текст в Git не сохраняется.

Сборка без PDF, например в CI: `python scripts/prepare_corpus.py --skip-pdf-check`. Она проверяет только воспроизводимость карточек и **не** заменяет сверку первоисточников. Якоря подтверждают страницу; точность пересказа и полнота условий требуют содержательной проверки. Полный корпус можно расширить в той же структуре; после изменения карточек индекс обновится автоматически.
