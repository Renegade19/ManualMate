# Корпус

30 документов D01–D30: по десять коротких адаптированных разделов руководств C-класса W205 (09/2018), E-класса W213 (06/2020) и GLC X253 (03/2020). Каждый документ хранится в `processed/Dxx.jsonl`.

`manifest.json` содержит 30 документов и три исходных PDF в `sources`. Поля документа: ID, раздел, модель, source_id, печатная и PDF-страница, путь к тексту. `selection.json` содержит тексты карточек и якоря исходных страниц. Карточки являются пересказами, `adapted: true`.

Темы: ASSYST PLUS, электронная проверка и долив масла, присадки и перелив, таблица давления шин, холодные шины, перезапуск контроля давления и проверка охлаждающей жидкости. Полный состав сервисов A/B и допуски конкретных двигателей в корпус не входят.

## Подготовка

```bash
python scripts/prepare_corpus.py --download
```

Скрипт загружает исходные PDF, проверяет SHA-256 и якоря выбранных страниц, собирает D01–D30. Номер печатной страницы равен номеру PDF-страницы минус три для указанных изданий.

Пересборка готовых карточек без исходных PDF: `python scripts/prepare_corpus.py --skip-pdf-check`. Исходные PDF и полный извлечённый текст исключены из Git.
