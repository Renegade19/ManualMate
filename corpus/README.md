# Корпус

Документы ещё собираются; кандидаты и их статус — [docs/sources.md](../docs/sources.md). Отвечает участник с ролью LLM.

## Структура

```text
corpus/
├── raw/            исходные PDF (не публикуются в Git, см. .gitignore)
├── processed/      фрагменты в JSONL
└── manifest.json   перечень документов
```

## manifest.json

```json
{
  "corpus_version": "2026-11-01",
  "documents": [
    {
      "doc_id": "w213-manual",
      "title": "Руководство по эксплуатации E-класса (W213)",
      "doc_type": "owner_manual",
      "models": ["W213"],
      "language": "ru",
      "edition": "год или номер издания с титульной страницы",
      "source": "откуда получен файл",
      "file": "raw/w213-manual.pdf",
      "sha256": "..."
    }
  ]
}
```

## Фрагмент в processed/*.jsonl

```json
{"chunk_id": "w213-manual-p412-c2", "doc_id": "w213-manual", "doc_type": "owner_manual", "models": ["W213"], "engines": [], "section": "Техническое обслуживание › ASSYST PLUS", "page": 412, "text": "..."}
```

`models: ["*"]` — фрагмент относится ко всем моделям (например, предписания по эксплуатационным материалам).

## Проверка перед включением документа

- Текст извлекается, это не скан.
- Номера страниц во фрагментах совпадают с печатными страницами руководства.
- Документ на русском и относится к нужной модели и годам выпуска.
- В тексте нет персональных данных и VIN.

Правила извлечения и разбиения — [spec/tech/rag.md](../spec/tech/rag.md).
