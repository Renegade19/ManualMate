| Роль | Часть проекта |

## Контракты

- `GET /api/vehicles` — модели, по которым есть документы.
- `POST /api/ask` — вопрос и автомобиль; ответ `answer`, `clarify` или `no_context`.
- `GET /api/health` — состояние индекса и Ollama.
- Для поиска и корпуса используется один токенизатор. Источники формируются из metadata документов.

Документ корпуса — самостоятельная индексируемая карточка раздела руководства. Карточки адаптированы из трёх PDF и связаны с печатными страницами. k = 5, глубина MRR = 5. Оценка Accuracy учитывает полноту ответа и сохранение условий источника.
