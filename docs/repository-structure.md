# Структура репозитория

| Каталог | Назначение |
| --- | --- |
| `frontend/` | Статический интерфейс и подключение к API |
| `backend/` | FastAPI, конфигурация, вызов Ollama |
| `search/` | Предобработка, индекс, BM25 |
| `corpus/processed/` | Документы D01–D30 в JSONL |
| `benchmark/results/` | Выдача и ответы прогона, оценки, четыре метрики |
| `tests/` | Pytest: поиск, API, benchmark |
| `spec/` | Спецификации продукта и компонентов |
| `docs/` | Контрольные точки, источники, скриншоты |
| `scripts/` | Подготовка корпуса и проверка документации |
| `.github/` | Проверка документации и шаблон PR |

Ветки КТ2: `docs/kt2-tasks` — спецификации и оформление, `feat/rag-core` — реализация; `main` — собранная версия.
