# Основной сценарий

Автомобиль → вопрос → ответ → источник → фрагмент документа.

В рабочем режиме вопрос «Где находится таблица рекомендованного давления шин?» возвращает ответ по руководству выбранной модели. Сноска раскрывает текст с подсветкой совпадений. Вопрос «Какое масло?» требует уточнения, стоимость ТО отсутствует в корпусе и приводит к отказу.

В прототипе КТ1 (`?demo=1`) ответы обозначены как демонстрационные. В benchmark используются только реальные результаты RAG.
