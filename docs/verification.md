## Найдено и исправлено при проверке

- На телефоне длинная подсказка в поле вопроса переносилась и обрезалась. Подсказка сокращена до «Например: когда менять антифриз».
- На телефоне номер источника стоял по центру многострочной строки. Выровнен по верху.
- В прошлой версии интерфейса: невидимые номера шагов, склейка вопроса с вариантом уточнения, ответ про моторное масло на вопрос про АКПП. Исправлено до смены дизайна.

## Ограничения

- Шрифт заголовков загружается из Google Fonts. Без интернета заголовки показываются шрифтом Georgia — вёрстка не ломается.
