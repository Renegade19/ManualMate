# Проверка

КТ2: тесты поиска, API и метрик — `python -m pytest -q`; структура и ссылки — `python3 scripts/check_docs.py`; генерация и выдача — [benchmark](../benchmark/README.md).

Интерфейс проверен в Chrome на ширинах 1440 и 390 px: ответ с источником, раскрытие фрагмента, подсветка, уточнение, отказ, ошибки и повтор, смена автомобиля, ограничение ввода.
