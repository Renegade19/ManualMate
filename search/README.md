# Search

Собственные инвертированный индекс и BM25. Готовые поисковые движки и библиотеки BM25 не используются.

| Файл | Назначение |
| --- | --- |
| `preprocess.py` | Один токенизатор корпуса и вопроса: регистр, леммы pymorphy3, сохранение кодов и допусков, отрицаний. Синонимы добавляет отдельная `query_terms()` только для запроса |
| `index.py` | TF, DF, длины, глобальные N и avgdl; JSON-кэш с хешем корпуса и версией токенизатора |
| `bm25.py` | Формула лекции, уникальные термы запроса, фильтр модели, понижение при несовпадении явно указанного двигателя, детерминированный порядок по score и doc_id |

Начальные параметры: k1 = 1.2, b = 0.75, k = 5. Кэш `.cache/index.json` не публикуется. После изменения корпуса он пересобирается при старте сервиса. Пустой запрос и отсутствие совпадений дают пустую выдачу. Индекс не знает эталоны benchmark.

Тесты: `python -m pytest tests/test_search.py`. Формула и ограничения — [rag.md](../spec/tech/rag.md), полный запуск — [README](../README.md).
