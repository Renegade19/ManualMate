# Search

Будущий модуль поиска. Реализации пока нет.

| Файл | Что | Ведущий |
| --- | --- | --- |
| `preprocess.py` | Защита технических обозначений, токенизация, лемматизация (`pymorphy3`), стоп-слова, синонимы для запроса | LLM |
| `index.py` | Инвертированный индекс, `N`, `DF`, `avgdl`, длины фрагментов; сохранение и загрузка | Backend |
| `bm25.py` | Ранжирование по формуле BM25 из методических указаний, фильтр по модели, порог отказа | Backend |

Готовые поисковые индексы (`rank-bm25`, `bm25s`, Elasticsearch и т. п.) не используются. Спецификация — [spec/tech/rag.md](../spec/tech/rag.md).
